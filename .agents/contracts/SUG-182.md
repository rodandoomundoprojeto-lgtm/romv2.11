# Contrato de Integração Full-Stack: SUG-182

> **Instrução ao Orquestrador:** Preencha e salve uma cópia deste contrato em `.agents/contracts/<ID-DA-TAREFA>.md` **antes** de acionar os subagentes `backend-logic` e `frontend-ui` em tarefas que envolvam ambas as camadas.

---

## 1. Contexto e Objetivo
- **ID da Tarefa:** `SUG-182`
- **Resumo:** Na home (`/`), substituir a seção de Curadoria IA em tempo real (`#vitrine-ia` — "Radar em Alta & Cruzamento Editorial") por um bloco rotativo de **Dossiês** (apenas alguns, para não poluir, com rotação a cada 40 minutos). A opção de Curadoria passa a existir no menu de navegação. A nova ordem coloca o bloco abaixo dos balões/linha "Pulsando agora no mapa".
- **Arquivos Alvo (Backend):** Nenhuma alteração funcional prevista (o endpoint `/api/vitrine-em-alta` e a expansão semântica da busca permanecem ativos para o fluxo de Curadoria; apenas o destino na Home muda). Leitura validada: `functions/api/vitrine-em-alta.js` (se existir sob `functions/api/`), `functions/api/resumo.js`, `functions/api/pesquisa.js`, `data/vitrine_ia.json`.
- **Arquivos Alvo (Frontend):** `index.html`, `200.html`, `app.js`, `styles.css`, `noticias.js`, `data/data.js`, `data/dossies.json`.

## 2. Especificação da Requisição (Frontend -> Backend Proxy Netlify/Cloudflare)

### 2.1. Endpoint de Dossiês (fonte de dados para o bloco rotativo)
- **Endpoint:** `GET /v2/dossies` (fallback: `GET /data/dossies.json`)
- **Método HTTP:** `GET`
- **Query Params / Body JSON:**
  | Parâmetro | Tipo | Obrigatório | Descrição |
  | :--- | :--- | :--- | :--- |
  | `_t` | `number` | Quando Refresh | Timestamp (`Date.now()`) para cache-busting |
- **Payload de Sucesso (HTTP 200):**
  ```json
  {
    "ok": true,
    "dossies": [
      {
        "slug": "string",
        "tipo": "permanente | especial",
        "titulo": "string",
        "subtitulo": "string",
        "descricao": "string",
        "status": "permanente | ao_vivo | em_breve | arquivo",
        "meta_info": "string",
        "veiculos_count": 0,
        "icone_ou_bandeira": "string",
        "data_inicio": "string|null",
        "data_fim": "string|null",
        "categoria": "string|null",
        "rota": "string"
      }
    ]
  }
  ```

### 2.2. Endpoint de Curadoria (inalterado — passa a ser acessado via menu de navegação)
- **Endpoint:** `GET /api/vitrine-em-alta`
- **Método HTTP:** `GET`
- **Query Params:**
  | Parâmetro | Tipo | Obrigatório | Descrição |
  | :--- | :--- | :--- | :--- |
  | `categoria` | `string` | Não | Filtro editorial |
  | `limite` | `number` | Não | Default `6` |
  | `acao` | `string` | Não | Se `expansao`, acionar expansão semântica da busca (`q`) |
  | `_t` | `number` | Quando Refresh | Cache-busting |

## 3. Especificação da Resposta (Backend -> Frontend)

### 3.1. Headers Obrigatórios
- Leitura normal: `Content-Type: application/json; charset=utf-8`, `Cache-Control: public, max-age=120, s-maxage=300`.
- Leitura com `_t` / `refresh=1`: `Cache-Control: no-store, no-cache, must-revalidate`.

### 3.2. Payload de Sucesso (Home — Bloco de Dossiês Rotativo)
- A home passará a consumir o pool de dossiês via `carregarDossiesV2()` / `/v2/dossies` / `/data/dossies.json` e renderizar um subconjunto rotativo.
- **Regras do subconjunto rotativo (SUG-182):**
  - Exibir **apenas alguns dossiês** (ex.: até 3 cards) para não poluir a home.
  - Rotacionar a seleção a cada **40 minutos** (`2400000 ms`).
  - Chave de cache local sugerida: `rom_cache_dossies_rotativos` (opcional; TTL de 40 min).

### 3.3. Payload de Erro / Fallback
```json
{ "ok": false, "error": "Mensagem descritiva", "dossies": [] }
```

## 4. Elementos DOM e Estados Visuais (Frontend)

- **Container Alvo (Home):** substituir/usar a slot da seção `#vitrine-ia` com novo bloco rotativo de dossiês (ex.: `#dossies-rotativos` com grid `#dossies-rotativos-grid`), mantendo classes de card existentes (`hubs-cards-grid`, `hub-home-card`, `dossie-status-badge`, `dossie-pulse-dot`).
- **Posição no fluxo (Ordem SUG-182):** o bloco rotativo de Dossiês deve ser renderizado **abaixo** do container `#pulsando-agora-container` (balões "Pulsando agora no mapa").
- **Estado de Loading:** classe `.is-loading` / skeleton nos cards (`dossie-loading` / `vitrine-ia-loading` já existentes).
- **Estado Vazio:** ocultar o bloco (`hidden`) quando não houver dossiês disponíveis.
- **Chave de Cache Local (`localStorage`):** limpar no refresh quando aplicável.
